# 💬 Talksy - Real-time Chat App

Welcome to **Talksy**, a modern, real-time chat application designed for seamless conversations. Whether it's one-on-one messaging or group chats, Talksy brings people closer together with a fast, responsive, and intuitive interface.

---

## 🌟 Features

- **Real-time Messaging** – Instantly send and receive messages.
- **Responsive Design** – Works flawlessly on desktop and mobile.
- **User Authentication** – Secure login and signup system.
- **Emoji Support** – Express yourself with emojis.
- **Media Sharing** – Send images and files with ease.
- **Customizable Profile** – Update profile picture and status.

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Realtime Communication:** Socket.io
